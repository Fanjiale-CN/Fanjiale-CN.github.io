01 / THE MATERIAL SYSTEM

Images are not flat.
They have roles.

One image can carry evidence, atmosphere, texture, hierarchy, and memory at once. Mixmatter separates those roles before recomposing them.
01 / SOURCE

Keep the identity.

Find the subject, context, and visual anchors that make the source unmistakably itself.

02 / PHOTOGRAPH

Spend the photograph.

Retain photography where it carries meaning; flatten or crop it where texture can do the job better.

03 / PRINT

Rebuild the hierarchy.

Halftone, duotone, graphic fields, and collage become structural tools rather than decorative filters.

02 / MATERIAL LAB

Read. Split.
Recompose.

Select a source and replay the reconstruction logic. This is a front-end demonstration using curated source/result pairs, not a live generation call.

04 / METHOD

Five moves.
One reconstruction.

  1. 01
    Disassemble

    Break the source into meaningful visual components.

  2. 02
    Recompose

    Rebuild hierarchy and spatial relationships.

  3. 03
    Reassign

    Move regions between photographic, printed, graphic, and collaged states.

  4. 04
    Reduce

    Quiet information that does not carry identity.

  5. 05
    Hierarchize

    Set dominant, secondary, and quiet zones.
