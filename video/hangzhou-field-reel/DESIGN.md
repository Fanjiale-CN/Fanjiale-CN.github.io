# Hangzhou Field Reel

HyperFrames-compatible composition: `composition.html`.

- 1920×1080 composition source / 15.4 seconds / silent.
- Five 3.4-second visual chapters with 0.4-second overlap.
- Four supplied photographs per chapter; all 20 photographs appear once.
- Entrance-only GSAP motion, 24px type rise, 1.04→1 image scale and calm `power` eases.
- Crossfades reveal the incoming scene over a fully visible outgoing scene.
- Palette and typography match the Hangzhou page design record.

The HyperFrames CLI package was not available in the repository environment. The checked-in composition retains the framework schema and timeline contract, while the published page runs the same five-scene grammar as a lightweight web-native field reel.
