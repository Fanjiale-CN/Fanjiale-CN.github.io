Press-Print

A source-aware visual reconstruction system for transforming user-supplied photographs into contemporary print-driven compositions.

View on GitHub ↗ v1.0.0 release ↗

OpenAI Skills-only Plugin prepared for submission. Public directory listing pending review.

Image-only v1.0 / MIT core / Fan Jiale · Galok

01 / Method

Reconstruction, not a filter.

Press-Print treats photography as source material. It preserves the structures that make a scene recognizable, then rebuilds the relationship between those structures into a new editorial composition.

02 / Principle

Preserve semantic identity, not visual completeness.

Source-aware

Structural anchors come from the supplied photograph rather than generic poster decoration.

Selective states

Photographic, printed, graphic, and collaged regions can coexist instead of forcing one uniform effect.

Image-only v1.0

Press-Print does not invent captions, place names, dates, slogans, labels, or decorative typography.

Open source

The core Skill, prompt system, documentation, and evaluation rubric are developed publicly on GitHub.

03 / Distribution

One core, multiple hosts.

The root Agent Skill remains the universal baseline. Platform-specific packaging adds only the metadata and file structure required by each host without silently changing the Press-Print v1.0 reconstruction behavior.
