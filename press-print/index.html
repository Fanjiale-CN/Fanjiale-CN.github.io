03 / METHOD

Five moves, one reconstruction.

The Skill is built around a sequence of visual decisions rather than a single global style filter.
  1. 01Disassemble

    Break the source into meaningful visual components.

  2. 02Recompose

    Rebuild the hierarchy and spatial relationships.

  3. 03Reassign

    Move regions between photographic, printed, graphic, and collaged states.

  4. 04Reduce

    Quiet or remove information that does not carry identity.

  5. 05Hierarchize

    Set dominant, secondary, and quiet zones.
