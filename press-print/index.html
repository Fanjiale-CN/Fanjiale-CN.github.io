03 / METHOD

THE FIVE
MOVES.

One sequence. No global filter.
  1. 01DISASSEMBLE

    Break the source into meaningful visual components.

  2. 02RECOMPOSE

    Rebuild hierarchy and spatial relationships.

  3. 03REASSIGN

    Move regions between photographic, printed, graphic, and collaged states.

  4. 04REDUCE

    Quiet information that does not carry identity.

  5. 05HIERARCHIZE

    Set dominant, secondary, and quiet zones.
