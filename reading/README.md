# Reading

Reading is Galok's historical-text desk: ancient texts, modern questions.

## V1 contract

- `/reading/` is a first-class section, separate from Essays, Research and Data.
- The hub is an editorial archive, not a chronological card wall.
- Historical material provides the period texture; the interface stays contemporary.
- `Reading / 001` is a working dossier around *Yantie Lun* and must not be presented as a finished essay until its edition trail and modern evidence are audited.
- Publication numbers are display metadata. Future article URLs should use durable semantic slugs.

## Evidence rules

1. Lock the text and edition before interpretation.
2. Preserve source, institution, rights and edition metadata.
3. Separate historical context from the modern evidence trail.
4. State where an analogy stops working.
5. Use public-domain or appropriately licensed historical media and keep attribution discoverable.

## V1 interface

Featured Reading → In Time → Read by Question → Reading Index → Source Shelf → How We Read.
