# Galok social assets

- `galok-default-og.svg` is the editable source for the default 1200×630 social card.
- `galok-default-og.png` is the crawler-safe raster export used by Open Graph and X/Twitter cards.
- Keep the Galok mark monochrome. Use the warm paper/ink system and the red editorial index only as an accent.
- Article and city pages should keep content-specific imagery when it is stronger than the default card; top-level/editorial landing pages may use the default card.
